ДЕМО-ПРИЛОЖЕНИЕ «ТОЛЬКО NODE.JS»
================================

ЧТО ДЕЛАЕТ ПРИЛОЖЕНИЕ
---------------------
На одной странице показаны две панели:

1. Слева — «Новое сообщение». Укажите имя отправителя и текст, затем нажмите
   «Отправить». Имя обязательно: от 1 до 60 символов. Текст: от 1 до 2000 символов.
2. Справа — «Полученные». Показывает отправителя, время получения и текст сообщения.
   Лента автоматически обновляется каждые 2 секунды. Страницы, открытые на этом
   сервере, видят общую ленту.

В приложении нет React, Express, SQLite или других npm-пакетов. Сервер и API написаны
на встроенных модулях Node.js. Страница использует обычные HTML, CSS и браузерный
JavaScript. Сообщения хранятся в массиве в оперативной памяти Node.js; показываются
последние 100, сервер сохраняет до 500 сообщений.

ВАЖНО ПРО ХРАНЕНИЕ
------------------
Это демонстрационная версия без базы и без файлового хранилища. Сообщения доступны,
пока работает текущий процесс Node.js. После остановки или перезапуска сервера
сообщения будут потеряны. Открытие сайта из другого браузера при работающем сервере
покажет ту же ленту, поскольку состояние хранит сервер.

ТРЕБОВАНИЯ И ЗАПУСК
-------------------
Нужен Node.js версии 18 или новее. Проверить установку можно командами:

  node --version
  npm --version

Откройте терминал Ubuntu и запустите:

  cd /home/karim/react_ex/react_only_node
  npm start

Откройте в браузере:

  http://localhost:3002

Остановить сервер — нажать Ctrl+C в том же терминале. Для автоматического
перезапуска Node.js при изменении файлов во время разработки:

  npm run dev

Порт по умолчанию — 3002. Можно задать другой порт:

  PORT=4000 npm start

Тогда откройте http://localhost:4000.

ФАЙЛЫ ПРОЕКТА
-------------
server.js — Node HTTP-сервер, статические файлы, API и массив сообщений в памяти.
public/index.html — HTML-разметка страницы и две панели приложения.
public/style.css — внешний вид, адаптивная раскладка и стили карточек сообщений.
public/app.js — отправка формы, получение и отображение сообщений в браузере.
package.json — команды npm start и npm run dev. Внешних зависимостей нет.

API И ТЕРМИНАЛ
--------------
Получить последние сообщения:

  curl 'http://localhost:3002/api/messages?limit=20'

Отправить тестовое сообщение из терминала:

  curl -X POST http://localhost:3002/api/messages \
    -H 'Content-Type: application/json' \
    -d '{"sender":"Анна","text":"Привет из терминала!"}'

Получить полный список, который сейчас находится в памяти:

  curl 'http://localhost:3002/api/messages?limit=500'

API GET ограничивает параметр limit значением от 1 до 500. Успешная отправка
возвращает JSON с id, именем sender, текстом и receivedAt — временем в ISO 8601/UTC.
В интерфейсе время отображается в местном часовом поясе браузера.

Если сервер остановлен, API недоступно, а сообщения не сохраняются. Чтобы хранить
сообщения между перезапусками, нужна постоянная запись: например SQLite, JSON-файл
или внешняя база данных.
